## 🧪 Week-by-Week Summary

### Week 1 — Foundations

This phase built a strong base in Java and algorithmic thinking.

- Arrays and their manipulation
- Binary search and sorted-array patterns
- Prefix sums and value transformations
- Problem decomposition and clean coding habits

See the [Week 1 folder](./Week-1/README.md) for all solutions.

### Week 2 — Linked Lists

This week focused on pointer-driven logic and data structure fluency.

- Reverse and merge linked lists
- Cycle detection and intersection checks
- Palindrome and middle-node traversal
- Simpler interview-style linked list patterns

See the [Week 2 exercises](./Week-2%20/README.md) for the full set.

### Week 3 — Stacks & Monotonic Patterns

This phase introduced stack-based problem solving and optimization tricks.

- Valid parentheses and balancing logic
- Monotonic stacks and next-greater problems
- Daily temperature and stock span patterns
- Deque and stack-based queue optimization

See the [Week 3 folder](./Week-3/README.md) for the complete breakdown.
