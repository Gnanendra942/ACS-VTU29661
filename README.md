## Week 1 — Summary

This week focused on foundational problem solving using Java. Topics covered include:

- Java basics: compiling and running programs
- Primitive types and control flow (if/switch, loops)
- Arrays and basic algorithms
- Problem-solving patterns for array manipulation and searching

See the [Week 1 folder](./Week-1/README.md) for individual problem write-ups and solutions.

## Week 2 — Summary (Starter)

Week 2 moves into core Java concepts and small project-style exercises:

- Object-oriented programming: classes, objects, fields, methods, and constructors
- Encapsulation and access modifiers
- Arrays and array-based algorithms revisited
- String manipulation and simple data structures

Add your Week 2 solutions under the `Week-2/` folder. Example structure:

```
Week-2/
├── 0001-example-problem/
│   ├── Solution.java
│   └── README.md
└── README.md
```

## How to contribute

2. Create a branch: `git checkout -b feature/<your-name>`

4. Commit and push your branch
5. Open a pull request describing your changes
